# 4チャレ本番オプチャ 運用

4日間体験プログラム（4チャレ）期間中のLINEオープンチャットの運用方針。常設の「求人内製化ラボ」とは別建てで、参加者の自己紹介・課題提出・反応を扱う。

## 関連

- [求人内製化ラボ マニュアル](../求人内製化ラボ/マニュアル)（常設オプチャのサポート運用・自己開示型の投げかけ）
- 自己紹介テンプレ・重要事項案内などは、社内の宣伝・4チャレ運営資料を参照する。

## 位置づけ

- 期間限定（4日間＋前後の数日）のオープンチャット
- 参加者の自己紹介（課題ゼロ）→ Day1〜Day4課題提出 → フィードバックの流れ
- ここでの反応の質が、後半の発言頻度・課題提出率・成約率に直結する

## 課題ゼロ（自己紹介）の設計

### オファー設計

- 課題ゼロ＝自己紹介
- 答えてくれた人に **特典プレゼント** を渡す
- 初動の参加率と発言ハードル下げの両方を狙う

### 自己紹介テンプレ（参加者に提示する）

3点フォーマットで書き出しのハードルを下げる。

- 業種
- 求人で今いちばん困っていること
- 4チャレで得たいこと

### 過去の自己紹介例の提示（必須）

課題ゼロ告知時に、**過去参加者の自己紹介例を3〜5件**先に貼る。書く側のハードルが一気に下がる。

例：

```
〇〇さん（建設業）：応募が3年で2件。今年こそ自社採用を実現したい
〇〇さん（美容室）：求人媒体に月15万。応募は来るがすぐ辞める。長く続く人を採りたい
〇〇さん（介護）：派遣依存で年間800万。コスト構造を変えたい
```

### 特典の渡し方（オプチャ投稿＋サポートリプライ＋特典用ビジネスLINE）

**特典用ビジネスLINEの友だち追加URLを告知に直接貼ると、自己紹介せずに特典だけ取られる抜け穴ができる**。これを塞ぐため、LINEのURLは告知では公開せず、**自己紹介投稿に対してサポートが個別リプライで案内する**運用にする。

#### 流れ

1. 山本：オプチャに課題ゼロ告知（特典用ビジネスLINEのURLは貼らない）
   - 自己紹介テンプレ・過去例を提示
   - 「投稿後、サポートから特典の受け取り方をお返しします」と案内
2. 参加者：オプチャに自己紹介を投稿
3. サポート（秘書含む）：投稿に **リプライ機能で**特典用ビジネスLINEの友だち追加URLを返す
   - 「〇〇さんありがとうございます！特典はこちらのLINEから受け取ってください→[友だち追加URL]」
4. 参加者：特典用ビジネスLINEを友だち追加し、オプチャでの表示名または指定キーワードを送る
5. ビジネスLINEの自動返信（または秘書確認後の手動返信）で特典URLが届く

#### この設計の効く理由

- 特典用ビジネスLINEのURLが **「自己紹介投稿へのリプライとしてしか出てこない」** 形になる
- 自己紹介していない人にはサポートからのリプライが返ってこない → 受け取れない
- リプライ自体は全員に見えるが、**「他人宛のリプライからURLをコピーする」のは心理的ハードルが高い**
- ロム専で抜けようとする人は元々購入意欲も低いので、フィルタリング機能として働く
- LINE内で完結するため、参加者の体験が自然。Day1前のリマインドや未提出フォローにもつなげやすい

#### サポートのリプライ運用（必ず守る）

- 特典用ビジネスLINEのURLは **必ずリプライ機能で**返す（投稿への返信）
- 新規メッセージとしてLINE URLを単独投下しない（投稿していない人にもアクセスされるため）
- リプライ内容は短くてよい：「〇〇さんありがとうございます！特典はこちらのLINEから受け取ってください→[URL]」程度
- 業種・状況に短く触れると、自己開示込みの反応として一石二鳥

#### 補強策（オプション・運用負荷が高くてもよい場合）

不正抜き取りを実質ゼロにしたい場合は、ビジネスLINE側で **表示名照合** を行う。

- 友だち追加後に「オプチャでの表示名」を送ってもらう
- 自己紹介投稿と表示名が一致しない場合は、特典送付を保留して目視確認する
- 自動化する場合は、キーワード応答の前に「表示名を送ってください」と案内する

最初は基本（リプライでLINE案内）だけで十分。不正が目立つようになれば照合を厳密にする。

#### 課題ゼロ告知テンプレ（オプチャ投稿用）

```
【課題ゼロ：自己紹介】

4チャレ参加ありがとうございます。
Day1の前に、自己紹介から始めてください。

▼ このオプチャに、3点を書いて投稿してください
・業種
・求人で今いちばん困っていること
・4チャレで得たいこと

▼ 過去の参加者の自己紹介例
〇〇さん（建設業）：応募が3年で2件。今年こそ自社採用を実現したい
〇〇さん(美容室)：求人媒体に月15万。応募は来るがすぐ辞める
〇〇さん(介護)：派遣依存で年間800万。コスト構造を変えたい

▼ 特典について
ご投稿いただいた方に、サポートから返信で
特典の受け取り方をお送りします。

メンバー同士の自己紹介を読むこと自体が、
業界の現状を立体的に捉える材料になります。
ぜひ他の方の投稿にも目を通してみてください。
```

ポイント：

- **特典用ビジネスLINEのURLは書かない**
- 「サポートから返信で」と明示することで、参加者は「投稿しないと届かない」と理解する
- 最後の一文で「他の人の自己紹介も読むメリット」を提示し、ロム専の読み込みを促す

## サポートメンバーの関与（必須）

山本一人で全員に反応するのは現実的に無理（30人なら15分超）。コメントの濃淡で不公平感が出る前に、最初から分担する。

### サポートメンバーがやること

- 課題ゼロを出した人の業種・地域・悩みに対して **自分の経験から短く反応**
 - 「美容室なんですね。僕も2年前同じ悩みで…」のような **自己開示込みの返し**
- スタンプ＋一言コメント（深く書かなくてよい）
- 「Day1楽しみですね」など軽く期待感を煽る
- 4チャレ修了後ラボに残る可能性が高い人を意識して関係を作る（ラボ活性化の種まき）

### サポートメンバーがやらないこと

- ハウツーを返す（教える役は山本に集約）
- 4チャレ後の有料商品の話を匂わせる
- 全員一律のテンプレ的反応（「ご参加ありがとうございます！」を量産しない）

## 山本が対応すべき自己紹介（拾う基準）

全員に山本が反応しようとせず、**深く拾う人**と**サポートに任せる人**を最初に切り分ける。

### 深く拾う5パターン

1. **具体的な数字を書いてくれた人**：「月30万」「応募2件」など。後の事例化候補
2. **過去成功事例と業種・規模が重なる人**：新聞販売店・建設業・美容室・介護・警備・製造など
3. **業界変革・問題意識を強く書いてくれた経営者（C層）**：JLC本命候補
4. **顧問型専門家（B層）**：社労士・税理士・コンサル・デザイナー・マーケター
5. **熱量が高くて場の温度を上げてくれる人**：「ずっと探していました」など前のめりな書き方

### サポートに任せる

- 一般的な業種で、サポートが自分の経験から返せる人
- 軽い挨拶程度の自己紹介の人
- すでにラボで顔見知りの人

### 山本のコメントに必ず含める要素（拾う人向け）

次のどれかを必ず1つ以上入れる。

- **悩みの再言語化**（「〇〇さんの状況、こういう構造ですよね」）
- **同業種の成功事例リファレンス**（「同じ業種で360万→7万にした方がいて…」）
- **4日間で何が見えるかの先取り**（「Day2の話、ド直球で刺さると思います」）
- **LPで約束したメッセージとの接続**（「業者に頼らず自社でコントロール、これが核心です」）

## 進め方の手順（運用フロー）

1. 課題ゼロ告知（特典オファー＋3点フォーマット＋過去例3〜5件・**特典用ビジネスLINEのURLは貼らない**）
2. 参加者の自己紹介投稿が始まる
3. **最初の3〜5件は山本が反応**して場の温度を決める
4. その後はサポート（秘書含む）が先輩として広く反応＋**リプライで特典用ビジネスLINEを案内**
5. 山本は **拾う5パターンに該当する人だけ深堀り**
6. 全件にスタンプか1コメント＋LINE案内のリプライは入れる（漏れない運用）
7. 参加者がビジネスLINEを追加 → 表示名または指定キーワード送信 → 自動返信または秘書確認後に特典URLを配布
8. Day1直前に山本が「明日Day1で会いましょう」と全体に1投稿で締める

## 副次効果：ラボ活性化への種まき

4チャレでサポートと交流した参加者は、終了後にラボへ戻ったとき **顔見知り** として残る。ラボでサポートの投稿に反応しやすくなり、活性化のリピート層になる。
